# CRM Action → CRM Need mapping

This is the canonical detailed mapping for the 79 catalog Actions. The value in
the `Need` column is `CRM Need.code`; the runtime link stored in
`CRM Action.need` is the corresponding `CRM Need.name`.

One Need may be linked to many Actions. `INTERNAL` Actions intentionally have
no Need and are stored with an empty `need` value.
